# Guide

Hand-written walkthrough of how to use the library. Start with **[Getting started](https://hotaritobu.github.io/musickit-api-mock/dev/guide/getting-started/index.md)** if this is your first time, then read **[Surfaces overview](https://hotaritobu.github.io/musickit-api-mock/dev/guide/surfaces/index.md)** to understand the three configuration surfaces, and **[Playwright integration](https://hotaritobu.github.io/musickit-api-mock/dev/guide/playwright/index.md)** for binding the mock to a browser-automation session.

For the full API surface (every class, field, and method), see the [Reference](https://hotaritobu.github.io/musickit-api-mock/dev/reference/index.md).
